    **getAuthorizationUrl(state):**
    Make a signed POST to `https://connectapi.garmin.com/oauth-service/oauth/request_token` using the oauth object (no user token needed for this step — consumer key only). Return the authorization redirect URL: `https://connect.garmin.com/oauthConfirm?oauth_token={requestToken}&state=${state}`. Wrap in try/catch and return a placeholder URL if consumerKey is missing: `https://connect.garmin.com/oauthConfirm?error=partner_approval_pending`.

    **exchangeCodeForTokens(code):**
    Exchange the oauth_verifier (passed as `code`) for an access token via POST to `https://connectapi.garmin.com/oauth-service/oauth/access_token`. Returns `{ success: true, tokens: { accessToken: oauthToken, refreshToken: oauthTokenSecret } }`. Note: Garmin OAuth 1.0a has no refresh concept — `refreshToken` stores the token secret for subsequent signing.

    **refreshTokens(refreshToken):**
    OAuth 1.0a tokens don't expire the same way — return the same token. Implementation: `return { accessToken: refreshToken }` (no-op).

    **revokeAccess(accessToken):** Return true (Garmin has no revocation endpoint in standard tier).

    **syncHealthData():** Return immediately: `{ provider: 'garmin', success: true, syncedAt: new Date(), recordsCount: { heartRate: 0, sleep: 0, activity: 0, bloodOxygen: 0, temperature: 0, hrv: 0, bloodPressure: 0, ecg: 0 }, errors: ['Garmin uses push model — data arrives via webhook, not on-demand pull'] }`.

    **validateWebhook(signature, payload):** HMAC-SHA256 of payload using `webhookSecret`, compare to signature using `crypto.timingSafeEqual`. Return false if webhookSecret is empty.

    **parseWebhookPayload(payload):** Extract from `GarminWebhookPayload`: get `userId` from `summaries[0]?.userId || dailies[0]?.userId`. `dataTypes` derived from which arrays are non-empty: if summaries present → `['daily_summary']`, if activities → `['activity']`.

    **Route — add before the final `export default router;` line:**
    ```typescript
    /**
     * POST /garmin/webhook
     * Receive push summaries from Garmin Health API
     * This endpoint is called by Garmin servers, not by users
     * No authentication middleware — validated by webhook signature
     */
    router.post('/garmin/webhook', async (req: Request, res: Response, next: NextFunction) => {
      try {
        // Guard: if partner credentials not configured, return 503
        if (!process.env['GARMIN_CONSUMER_KEY']) {
          res.status(503).json({
            status: 'error',
            message: 'Garmin integration pending partner program approval — GARMIN_CONSUMER_KEY not configured',
          });
          return;
        }

        // Validate webhook signature
        const signature = req.headers['x-garmin-signature'] as string || '';
        const rawBody = JSON.stringify(req.body); // NOTE: if using express.json(), body is already parsed
        if (!garminProvider.validateWebhook(signature, rawBody)) {
          res.status(401).json({ status: 'error', message: 'Invalid webhook signature' });
          return;
        }

        // Parse payload
        const { userId, dataTypes } = garminProvider.parseWebhookPayload(req.body);

        // Find patient's Garmin device by Garmin userId stored in serialNumber
        const device = await prisma.wearableDevice.findFirst({
          where: {
            deviceType: 'garmin',
            serialNumber: userId,
            isConnected: true,
          },
        });

        if (!device) {
          // Garmin userId not matched — log but return 200 to prevent Garmin retry spam
          res.json({ status: 'success', message: 'No matching device found — ignored' });
          return;
        }

        // Extract and persist readings from summaries
        const summaries = (req.body as any).summaries || (req.body as any).dailies || [];
        let totalRecorded = 0;

        for (const summary of summaries) {
          const readings = garminProvider.extractReadingsFromSummary(summary, device.patientId, device.id);
          for (const r of readings) {
            await wearableService.recordReading({
              patientId: device.patientId,
              wearableId: device.id,
              type: r.type as any,
              value: r.value,
              unit: r.unit,
              metadata: { source: 'garmin_webhook', summaryId: summary.summaryId },
            });
            totalRecorded++;
          }
        }

        await prisma.wearableDevice.update({
          where: { id: device.id },
          data: { lastSyncAt: new Date() },
        });

        res.json({ status: 'success', data: { recordsStored: totalRecorded } });
      } catch (error) {
        next(error);
      }
    });
    ```
