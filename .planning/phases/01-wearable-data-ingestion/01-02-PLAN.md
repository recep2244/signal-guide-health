Withings meastype codes (confirmed from official docs):
- `9` = diastolic blood pressure (mmHg)
- `10` = systolic blood pressure (mmHg)
- `11` = heart rate (bpm)
- `54` = SpO2 percentage
- `71` = body temperature (°C)

Withings value scaling: `actual = value * Math.pow(10, unit)` where `unit` is the exponent (typically negative). Example: `{ value: 9750, unit: -2 }` → `9750 * 10^-2 = 97.5`.

    **exchangeCodeForTokens(code):**
    POST to `https://wbsapi.withings.net/v2/oauth2` with `Content-Type: application/x-www-form-urlencoded`. Body must include `action=requesttoken` (this is the non-standard Withings requirement — without it the request fails with error 293). Parse response JSON: `{ status: 0, body: { access_token, refresh_token, expires_in, userid } }`. Return `{ success: true, tokens: { accessToken, refreshToken, expiresAt: new Date(Date.now() + expires_in * 1000) } }`. On non-zero status, return `{ success: false, error: response.error }`.

    **refreshTokens(refreshToken):**
    Same endpoint, body: `action=requesttoken&grant_type=refresh_token&client_id=...&client_secret=...&refresh_token=...`. Critically, ALWAYS return BOTH new access_token AND new refresh_token. Withings invalidates the old refresh token immediately on use — callers must persist both tokens or permanent auth failure occurs after 3 hours.

    **Private getMeasurements(accessToken, since):**
    POST to `https://wbsapi.withings.net/measure` with `Authorization: Bearer {accessToken}`. Body: `action=getmeas&startdate={unixTimestamp}&enddate={unixTimestamp}&meastypes=9,10,11,54,71`. startdate/enddate are Unix seconds. Response: `{ status: 0, body: { measuregrps: [ { date: unix, measures: [ { type: int, value: int, unit: int } ] } ] } }`. Use `scaleWithingsValue(value, unit)` to compute actual values.

    **Private scaleWithingsValue(value, unit):**
    ```typescript
    private scaleWithingsValue(value: number, unit: number): number {
      return value * Math.pow(10, unit);
    }
    ```

    **syncHealthData(accessToken, since):**
